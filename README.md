# 🎧 Velvet Noise

> Where sound drips like velvet and silence learns to glow.

Velvet Noise is a modern, aesthetic music player built with HTML, CSS, and JavaScript.  
It focuses on creating an immersive, emotional listening experience with a glowing, dark-themed UI.

---

## ✨ Features

- 🎵 Beautiful custom music player UI  
- 🌌 Purple neon glow aesthetic  
- ⏯️ Play / Pause / Next / Previous controls  
- 📀 Playlist support with songs & covers  
- 📱 Fully responsive design (desktop + mobile)  
- 🎨 Glassmorphism + blur effects  
- ⚡ Lightweight and fast performance  

---

## 🖤 Theme

- Dark cinematic interface  
- Neon purple accent glow  
- Soft blurred backgrounds  
- Emotional, dreamy music atmosphere  

---

## 🧠 Tech Stack

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)
